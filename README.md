# ICH Final Project

Interactive console application for searching movies in the Sakila MySQL database.

## Project goal

The goal of this project is to create a Python console application that allows users to search movies from the Sakila MySQL database.

## Current progress

- Project structure created
- Virtual environment configured
- MySQL connection works
- Keyword search works using a parameterized SQL query
- Database credentials are stored in `.env` and loaded through `config.py`
